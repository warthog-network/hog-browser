              Setting up your exit node
              
                          
                
                        1. In Containers, click Tailscale, choose Docker Engine if it is available, then Run. Open the running tailscale container, press Sign in, open the link, and log in. Hog appears in your tailnet as "hog". If you move Tailscale from Docker Desktop, delete the old hog or hog-1 machine in the admin console before signing in again, then approve the new one as an exit node.
                          2. 
                
                        2. In the , open hog's menu, choose Edit route settings, and turn on Use as exit node.
                          3. 
                
                        3. On your phone, install the Tailscale app, sign in to the same account, tap Exit node, and pick hog.
                          4. 
                
                        4. Check: browse a site such as youtube.com. Hog's container has IPv4 and IPv6 forwarding, so Private DNS such as one.one.one.one works too. If pages hang, set Private DNS to Automatic and try again, and make sure the container is running.
                          5. 
                
                        5. Note: the login is kept in the hog-tailscale-state volume, so Recreate keeps hog's identity. If you delete that volume, remove the old hog from the admin console before logging in again.
